# superagent-playground

Sandbox repository for the dsh-superagent prototype.

## 社区本地部署参考页

直接用浏览器打开 `index.html`，或在此目录运行 `python3 -m http.server 8000` 后访问 `http://localhost:8000/`。

页面重点：公开社区在真实硬件上运行 DeepSeek V4.1 Flash（1017 权重）的**方案、成本与实测结果**，并回答「0909 与 1017 权重差多少、本地该用哪一个」。不是官方 API / 模型链接索引。

- 12 组社区方案：1–8 卡 RTX PRO 6000、2/4 卡 DGX Spark、DGX Station、Mac Studio，按硬件档位筛选、按速度排序。
- 版本对比：0909 与 1017 的 48 个权重分片字节数完全相同（510,296,708,312 B），但 48/48 个分片哈希不同；给出社区同机实测与独立基准，并建议统一使用 1017。
- 成本参考：2026 年硬件价格、实测功耗、每百万输出 token 的示例估算与 API 对照。
- 边界与踩坑：装不下、卸载掉速、长上下文失败、推理循环与高并发报错。

使用 `node --test tests/content.test.js` 运行内容与筛选/排序逻辑测试。

页面是人工整理的静态资料快照，并非实时行情服务。数据来自公开的 Hugging Face 发布包、GitHub 配方仓库、社区日报、论坛实测贴与公开报价页；均为发布者自报，未独立复测，跨来源比较只到 ±20–30% 量级。价格、硬件配置及性能会随来源和部署条件变化，请在采购或部署前核对页面链接的原始资料。
