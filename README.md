# superagent-playground

Sandbox repository for the dsh-superagent prototype.

## 部署观察页面

直接用浏览器打开 `index.html`，或在此目录运行 `python3 -m http.server 8000` 后访问 `http://localhost:8000/`。

使用 `node --test tests/source-check.test.js` 运行在线检查逻辑测试。

页面是人工整理的静态资料快照，并非实时新闻服务。可点击“检查仓库更新”查询官方模型仓库的最后修改时间、版本和最近提交历史（不是部署新闻或模型发布公告）；该操作需要联网，不会更新或核验快照内容。价格、硬件配置及性能会随来源和部署条件变化，请在采购或部署前核对页面链接的原始资料。
