# superagent-playground

Sandbox repository for the dsh-superagent prototype.

## 社区本地部署参考页

直接用浏览器打开 `index.html`，或在此目录运行 `python3 -m http.server 8000` 后访问 `http://localhost:8000/`。

页面整理 DeepSeek V4.1 Flash 1017 权重的社区本地部署方案、成本及实测结果，包含 10 组社区方案、硬件筛选、速度排序、部署注意事项和成本示例。美元、欧元价格以页面注明的示例汇率换算为人民币，不是实时汇率或国内报价。功耗成本注明电价、利用率及其他假设。

使用 `node --test tests/content.test.js` 运行内容与筛选/排序逻辑测试。

页面是人工整理的静态资料快照，并非实时行情服务。数据来自公开社区资料及报价；测量结果为发布者自报，未独立复测，不同测试条件不能直接横比。价格、硬件配置及性能会随来源和部署条件变化，请在采购或部署前核对原始资料。
